# 🍽️ Sabor & Arte - PWA Restaurante

Site PWA completo com catálogo de pratos, porções e bebidas + carrinho de pedidos.

## 📁 Arquivos
- `index.html` - Site com catálogo e carrinho
- `manifest.json` - Configuração do PWA
- `sw.js` - Service Worker (funciona offline)
- `icons/` - Ícones do app (192x192 e 512x512)

## 🚀 Publicar no GitHub Pages
1. Crie um repositório no GitHub
2. Faça upload de TODOS os arquivos (mantendo as pastas)
3. Vá em **Settings → Pages → Branch: main → Save**
4. Aguarde 2-5 minutos e acesse o link!

## 📱 Gerar o APK (PWABuilder)
1. Acesse https://www.pwabuilder.com/
2. Cole o link do seu site do GitHub Pages
3. Clique em **Package for Android**
4. Baixe o APK e instale no celular!
